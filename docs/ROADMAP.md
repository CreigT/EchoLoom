# Roadmap

## Now (v0 — this repo)

- Runnable multi-agent workflow with human script approval
- Studio UI and live event stream
- Security primitives and audit log
- Mock LLM / TTS / music / payments adapters

## Next 30 days

- Persist projects in Postgres
- Swap mock LLM adapter for a real provider behind the same interface
- Real file uploads for voice notes + speech-to-text adapter
- Stripe invoice draft on `finance.invoiced`

## 60 days

- Durable event bus
- Voice provider integration with explicit consent ledger
- Rights database adapter and release PDF generation
- Private gallery links for finished masters

## 90 days

- Public marketplace listing flow
- Royalty split escrow
- Analytics retraining loop on approval / rejection outcomes
- Accessibility masters (captions, paced editions)

## Experiments (do not ship without consent review)

1. Living Chapter — listeners ask the story questions; generate continuation audio
2. Emotional Arc Mirror — mood signals reshape music on later listens
3. Ancestral Voice Weave — blend verified family samples across generations

## Risks to watch

- Deepfake or consent disputes around voice cloning
- Platform policy changes restricting synthetic audio
- Over-automation that flattens distinct human voices

## Opportunities

- Genealogy platform pipelines
- School oral-history programs
- White-label agent swarm for publishers
